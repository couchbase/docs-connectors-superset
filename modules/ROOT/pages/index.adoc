The Couchbase SQLAlchemy Connector integrates Couchbase Analytics tabular views and Capella Columnar instances with the open source data exploration and visualization platform Apache Superset.
--

== Install the CouchbaseSQL Alchemy Connector
To install the Couchbase SQLAlchemy Connector, open the command prompt (`cmd`), and enter the following:

[source, console]
----
pip install couchbase-sqlalchemy
----

== Install Apache Superset

Download and install https://superset.apache.org/docs/quickstart[Apache Superset] following the official documentation.

== Configure the Connection in Superset

Launch Apache Superset and set up a new database connection. 
Select Couchbase as the database type and provide the necessary connection details.

== Create Tabular Analytics View

In Couchbase Analytics, define https://docs.couchbase.com/columnar/sqlpp/5a_views.html#TAV[Tabular Analytics Views]. These views act as non-materialized views, specifying schemas along with primary and foreign keys for collections or subqueries.


== Use the Couchbase Superset Connector

. To create tabular views for graphical visualization, we start by loading data into a collection. For this example, we'll use a dataset called https://www.kaggle.com/datasets/gregorut/videogamesales[video_game_sales.json].

. Ensure your `video_game_sales.json` file is accessible in a location that your database system can read from. This file contains structured JSON data about video game sales.

. Create External dataset using `video_game_sales`.

. On querying Select * from `Default.Default.video_game_sales limit 1`. 

+
[source, console]
----
[
  {
   "video_game_sales": {
     "_columnar_ID": "691c68ce-1dd3-9e94-7a47-c041eb87fe8c",
     "rank": "74",
     "name": "Animal Crossing: New Leaf",
     "platform": "3DS",
     "year": "2012",
     "genre": "Simulation",
     "publisher": "Nintendo",
     "na_sales": "2.01",
     "eu_sales": "2.32",
     "jp_sales": "4.36",
     "other_sales": "0.41",
     "global_sales": "9.09"
   }
 }
]
----

. To create a tabular analytics view from the video_game_sales collection, execute the following command:
+
[source, console]
----
CREATE OR REPLACE ANALYTICS VIEW
video_game_sales_1 (_columnar_ID string, rank int, name string, platform string, year string, genre string, publisher string, na_sales double, eu_sales double, jp_sales double, other_sales double, global_sales double)
DEFAULT NULL PRIMARY KEY (__id)
NOT ENFORCED AS
SELECT video_game_sales.* FROM video_game_sales;
----

=== Visualization

To visualize the data, please follow these steps in Apache Superset:

. Navigate to the Dataset section in the Superset dashboard.
. Select `Couchbase-Analytics-With-SSL` as the database.
. Choose *Default* as the schema.
. Look for the view named *video_game_sales_1* to proceed with the data visualization.
